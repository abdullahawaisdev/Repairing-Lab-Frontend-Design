# 🔧 Repairing Lab

A modern and responsive **mobile repair service website** built using **HTML5, CSS3, Bootstrap 4.6, Font Awesome 5, and jQuery**. 📱💻

The website is designed for a mobile repairing business and includes service information, repair categories, featured products, business opportunities, contact information, social media icons, and an embedded Google Maps location. 🌐🛠️

---

## 🌟 Features

* 📱 Mobile repair service website
* 🧭 Responsive navigation bar
* 📌 Fixed navigation with smooth scrolling
* 🏠 Home section with hero image
* 🔍 Explore section
* 💼 Business opportunities section
* 🎥 Repair-related video section
* 🛠️ Multiple repair services
* 🔋 Battery repair
* 🔌 Charging repair
* 💻 Software repair
* 📱 Screen repair
* 🛒 Mobile/product showcase
* ⭐ Featured services and components
* 🖼️ Image-based sections
* 📞 Contact section
* 🌐 Social media icons
* 📍 Embedded Google Maps location
* 📱 Responsive design for different screen sizes

## 📱 Responsive Design

Bootstrap's responsive grid system is used throughout the website.

For example:

```html
<div class="col-lg-4">
    ...
</div>

<div class="col-lg-8">
    ...
</div>
```

This allows the website layout to adapt to different screen sizes. 📱💻🖥️

---

## ✨ Smooth Scrolling

The website uses CSS to provide smooth scrolling between sections:

```css
html {
    scroll-padding-top: 80px;
    scroll-behavior: smooth;
}
```

This makes navigation between sections smoother and prevents content from being hidden behind the fixed navigation bar.

## 🚀 How to Run

1. 📥 Download or clone this repository.
2. 📂 Keep all images, CSS files, and the video in the correct project directory.
3. 💻 Open the project in **Visual Studio Code**.
4. 🌐 Open `index.html` in your browser.
5. ⚡ For the best development experience, use the **Live Server** extension in VS Code.
